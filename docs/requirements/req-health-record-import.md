# 需求：健康记录批量导入功能 (Health Record Batch Import)

## 基本信息
- **标题**：用户健康记录批量导入（Excel/CSV）
- **保存路径**：`/docs/requirements/req-health-record-import.md`
- **状态**：已澄清 (Clarified)
- **创建日期**：2025-12-19
- **优先级**：高 (High)
- **背景**：用户可能已有历史健康记录（来自其他设备/应用/纸质记录），需要批量导入到平台中。当前系统仅支持单条记录手动录入，对于大量历史数据录入效率低下。
- **业务价值**：
  - 降低用户迁移成本，提升用户接纳度
  - 支持历史数据完整性，便于长期健康趋势分析
  - 提升平台竞争力（对标其他健康管理应用）

## 范围定义

### MVP 阶段（Phase 1：标准模板导入）

#### 范围内
1. **导入格式支持**：
   - Excel (.xlsx)
   - CSV (.csv, UTF-8 编码)

2. **标准导入模板**：
   - 提供官方模板下载（Excel 和 CSV 两种格式）
   - 模板包含必填/选填字段说明、示例数据、格式要求

3. **字段映射**（固定字段顺序）：
   - 成员名称（必填）- 用于关联家庭成员
   - 测量时间（必填）- 支持多种日期时间格式
   - 收缩压（必填）- 30-250 mmHg
   - 舒张压（必填）- 30-250 mmHg
   - 心率（可选）- 30-150 bpm
   - 标签（可选）- 多个标签用分号分隔
   - 备注（可选）- 文本

4. **成员匹配机制**：
   - 通过成员名称（full_name）匹配家庭成员
   - 支持"Self/自己/本人"特殊标识
   - 大小写不敏感，自动去除前后空格

5. **时区处理**：
   - 默认时区：北京时区（UTC+8 / Asia/Shanghai）
   - 如果时间字符串已包含时区信息，则使用原时区
   - 支持的时间格式：
     - ISO 8601: `2025-12-19T08:30:00+08:00`
     - 标准格式: `2025-12-19 08:30:00`
     - 简化格式: `2025/12/19 8:30`

6. **数据验证**：
   - 必填字段检查
   - 血压范围校验（收缩压 > 舒张压）
   - 心率范围校验
   - 成员存在性校验
   - 时间格式校验
   - 重复数据检测（可选：同一成员、同一时间的记录）

7. **错误处理**：
   - 逐行验证，记录所有错误
   - 支持"跳过错误行继续导入"模式
   - 导入结果摘要：
     - 总行数
     - 成功导入数
     - 失败行数及详细错误（行号 + 错误原因）
   - 错误日志下载（CSV 格式）

8. **权限控制**：
   - 用户只能导入自己家庭的成员数据
   - 成员名称必须在用户的家庭成员列表中
   - 管理员无特殊权限（仍只能导入自己的家庭数据）

9. **性能要求**：
   - 支持单次导入最多 1000 条记录
   - 前端上传文件大小限制：5MB
   - 后端异步处理（避免阻塞）
   - 导入进度反馈（可选：WebSocket 或轮询）

10. **UI/UX**：
    - 在"健康记录"页面增加"导入"按钮
    - 导入流程：
      1. 下载模板
      2. 选择文件上传
      3. 预览前 10 行数据
      4. 确认导入
      5. 显示导入结果（成功/失败统计）
      6. 下载错误日志（如有错误）

#### 范围外（后续版本）
- **智能格式识别**：自动分析任意格式的 CSV/Excel
- **自然语言映射**：用户描述列映射规则（如"第3列是收缩压"）
- **AI 辅助转换**：智能建议字段映射关系
- **规则保存与复用**：保存导入配置模板供下次使用
- **历史导入记录**：查看导入历史、回滚功能
- **批量更新**：通过导入更新已有记录
- **其他数据源**：Apple Health、Google Fit、小米健康等
- **图片识别**：OCR 识别纸质记录

## 用户故事 (User Stories)

### US-1: 下载导入模板
**作为** 普通用户  
**我想要** 下载官方提供的健康记录导入模板（Excel/CSV）  
**以便于** 我可以按照标准格式整理我的历史数据

**验收标准**：
- [ ] 在"健康记录"页面有明显的"导入数据"按钮
- [ ] 点击后弹出导入向导，第一步是"下载模板"
- [ ] 提供两种格式下载：Excel 和 CSV
- [ ] 模板包含表头说明和 2-3 条示例数据
- [ ] 模板文件名清晰易懂（如：`健康记录导入模板.xlsx`）

---

### US-2: 上传并验证导入文件
**作为** 普通用户  
**我想要** 上传整理好的健康记录文件，并在导入前看到数据预览  
**以便于** 我可以确认数据格式正确，避免导入错误数据

**验收标准**：
- [ ] 支持拖拽或点击上传 Excel/CSV 文件
- [ ] 文件大小限制 5MB，超出后提示错误
- [ ] 上传后显示前 10 行数据预览
- [ ] 预览显示每列的字段名和样例值
- [ ] 如果格式明显错误（如缺少必填列），立即提示

---

### US-3: 区分导入的成员数据
**作为** 普通用户  
**我想要** 在导入文件中指定每条记录属于哪个家庭成员  
**以便于** 我可以同时导入自己和家人的历史数据

**验收标准**：
- [ ] 模板中包含"成员名称"列（第一列）
- [ ] 支持通过成员姓名匹配（如"张三"、"Self"、"自己"）
- [ ] 如果成员名称不存在，该行标记为错误，不导入
- [ ] 导入结果摘要中显示每个成员的导入统计

---

### US-4: 时区自动处理
**作为** 普通用户  
**我想要** 导入的测量时间自动识别为北京时区  
**以便于** 我不需要手动转换时区，可以直接填写本地时间

**验收标准**：
- [ ] 如果时间字符串没有时区信息（如 `2025-12-19 08:30:00`），默认为北京时区（UTC+8）
- [ ] 如果时间字符串包含时区（如 `2025-12-19T00:30:00Z`），则使用原时区
- [ ] 导入后，数据库统一存储为 UTC 时间
- [ ] 前端显示时自动转换为用户当前时区（或北京时区）

---

### US-5: 查看导入结果与错误日志
**作为** 普通用户  
**我想要** 在导入完成后看到详细的结果统计和错误信息  
**以便于** 我可以了解哪些数据导入失败，并修正后重新导入

**验收标准**：
- [ ] 导入完成后显示结果摘要：
  - 总行数（排除表头）
  - 成功导入数
  - 失败行数
- [ ] 显示失败行的详细列表（行号 + 错误原因）
- [ ] 支持下载错误日志 CSV 文件
- [ ] 错误日志包含原始数据和错误原因，方便用户修正

## 边界与约束

### 边界场景
1. **空文件**：提示错误，不允许导入
2. **仅有表头无数据**：提示错误
3. **超过 1000 行**：提示错误，建议分批导入
4. **文件编码非 UTF-8**：CSV 导入失败，提示编码错误
5. **Excel 多个工作表**：仅读取第一个工作表，其他忽略
6. **同一时间的重复记录**：允许导入，不做去重（由用户决定）
7. **未来时间**：允许导入（可能是预约或计划测量）
8. **成员名称空白**：标记为错误行
9. **标签包含非法字符**：自动过滤或转义

### 技术约束
1. **数据库性能**：批量插入使用事务，避免逐条插入
2. **内存限制**：大文件分块读取，避免一次性加载到内存
3. **前端性能**：大文件上传使用分片上传（可选）
4. **时区处理**：后端统一使用 `datetime.now(UTC)` 和 `pytz`

### 非功能需求
1. **可用性**：导入流程不超过 3 步，操作简单明了
2. **可靠性**：导入失败不影响已有数据，使用事务保证原子性
3. **可维护性**：导入逻辑独立封装，便于后续扩展智能导入
4. **国际化**：所有提示信息支持多语言（中英文）

## 标准模板格式

### Excel 模板结构
| 成员名称 | 测量时间 | 收缩压 | 舒张压 | 心率 | 标签 | 备注 |
|---------|---------|-------|-------|-----|------|------|
| **Member Name** | **Timestamp** | **Systolic** | **Diastolic** | **Heart Rate** | **Tags** | **Note** |
| **（必填）** | **（必填）** | **（必填）** | **（必填）** | （可选） | （可选） | （可选） |
| Self | 2025-12-19 08:30:00 | 120 | 80 | 72 | 晨起;空腹 | 早晨测量 |
| 张三 | 2025-12-18 20:00:00 | 135 | 85 | 78 | 晚餐后 | 感觉有点头晕 |

**说明**：
- 第1行：中文字段名
- 第2行：英文字段名
- 第3行：必填/可选说明
- 第4行起：示例数据

### CSV 模板结构
```csv
成员名称,测量时间,收缩压,舒张压,心率,标签,备注
Member Name,Timestamp,Systolic,Diastolic,Heart Rate,Tags,Note
（必填）,（必填）,（必填）,（必填）,（可选）,（可选）,（可选）
Self,2025-12-19 08:30:00,120,80,72,晨起;空腹,早晨测量
张三,2025-12-18 20:00:00,135,85,78,晚餐后,感觉有点头晕
```

**编码**：UTF-8 with BOM（确保 Excel 正确显示中文）

## 数据流程

### 导入流程
```
用户 → 点击"导入数据" 
    → 下载模板 
    → 整理数据 
    → 上传文件 
    → 后端解析文件 
    → 逐行验证 
    → 批量插入数据库 
    → 返回结果摘要 
    → 用户查看结果/下载错误日志
```

### 后端处理流程
```python
1. 接收文件上传 (Excel/CSV)
2. 解析文件内容
   - Excel: 使用 openpyxl 或 pandas
   - CSV: 使用 csv 模块或 pandas
3. 逐行验证：
   - 解析成员名称 → 匹配家庭成员 ID
   - 解析测量时间 → 转换为 UTC 时间
   - 验证血压、心率范围
   - 解析标签（分号分隔）
4. 收集成功行和错误行
5. 批量插入成功行（使用事务）
6. 返回结果：
   {
     "total": 100,
     "success": 95,
     "failed": 5,
     "errors": [
       {"row": 10, "reason": "成员名称不存在"},
       {"row": 25, "reason": "收缩压必须大于舒张压"}
     ]
   }
```

## 未来扩展（智能导入）

### Phase 2: 智能格式识别
1. **自动分析文件结构**：
   - 识别表头位置（可能在第2行、第3行）
