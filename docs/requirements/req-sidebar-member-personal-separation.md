# Requirement: 左侧菜单区分“家庭成员数据页面”与“个人账户页面”

## 基本信息
- 类型: Enhancement
- 优先级: Medium
- 目标版本: Next Iteration

## 背景
当前左侧菜单将“仪表盘/健康记录/既往病史/成员管理”和“个人信息/用户设置”并列展示，用户难以快速理解哪些页面作用于“当前选中家庭成员”，哪些页面只作用于“当前登录用户自己”。

## 需求目标
增强信息架构与可理解性，降低用户误操作概率，提升家庭场景可用性。

## 需求范围
- 对左侧菜单做视觉分组：
  - 家庭成员数据
  - 个人账户
  - 管理（按角色展示）
- 保持现有权限控制逻辑不变。
- 不改变业务权限边界，仅优化导航表达。

## 交互与文案
- 家庭成员数据分组包含：
  - 仪表盘
  - 健康记录
  - 既往病史
  - 成员管理
- 个人账户分组包含：
  - 个人信息
  - 用户设置
- 管理分组包含（按角色动态显示）：
  - 用户管理（ADMIN/SUPER_ADMIN）
  - 超级管理员设置（SUPER_ADMIN）

## 验收标准
1. 用户进入系统后，左侧菜单能够看到清晰分组标题。
2. 家庭相关页面与个人页面不再混杂显示。
3. 管理分组仅在对应角色下可见。
4. 中英文界面均显示正确分组文案。

## 实施说明
- 前端改造点：`frontend/src/components/Layout.js`
- i18n 改造点：
  - `frontend/src/i18n/locales/zh/translation.json`
  - `frontend/src/i18n/locales/en/translation.json`

## 非目标
- 本需求不引入新权限体系。
- 本需求不自动切换成员，不调整数据归属逻辑。
