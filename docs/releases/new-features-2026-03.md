# 健康记录平台 - 最近新增功能说明 (2026年3月)

## 一、家庭成员既往病史管理 MVP
**1. 功能描述**
针对用户需要为家庭成员维护完整背景记录的场景，支持长期健康管理。这允许用户在查看血压/心率等指标时兼顾成员病史，从而更准确地分析指标。

**2. 修改内容**
- **前端模块**：新增独立的 `MedicalHistory` 管理页面。并在新增健康记录页面增加既往病史二次入口。
- **后端模块**：增加了基于 `Blueprint` 的服务端点与 `MedicalHistoryManager` 提供核心 CRUD。
- **配置与测试**：针对性新增了 E2E 和 Pytest(`test_medical_history.py`)，覆盖异常越权、数据格式与业务流程校验。

**3. 设计变更**
- **数据结构扩展**：在已有模型基础上，新增了 `MedicalHistory` 实体，结合 `(member_id, onset_date desc)` 的复合索引支持。
- **隔离机制增强**：完全复用基于 `household_id` 和 `member_id` 的家庭租户隔离。

## 二、云原生部署及工作流演进
**1. 功能描述**
为适应分支隔离的测试和演示环境，将项目的 CI/CD 工作流从原有的 App Service 单机部署转向云原生工作流。

**2. 修改内容**
- 新增 `workshop-deploy.yml` 分支部署流，更新并清理 `.dockerignore` 等构建级配置文件。

**3. 设计变更**
- 以容器为核心调度单元进行前后端打包结构解耦。
