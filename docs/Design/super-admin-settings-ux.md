# Super Admin Setting 页面及导航改造 UX 设计说明

**版本：** 1.0  
**日期：** 2025-12-01  
**作者：** BMad

---

## 1. 设计目标

1. 清晰区分不同角色的设置入口，将个人设置 (“User Setting”) 与超级管理员专属配置 (“Super Admin Setting”) 分离。  
2. 提供超级管理员可视的健康阈值管理容器，为后续表单与数据展示组件奠定布局基础。  
3. 保持移动端与桌面端体验一致，确保导航栏、抽屉菜单在不同视口下均能正确呈现。  
4. 满足无障碍与国际化要求，菜单命名、图标与提示文案皆可正确在中英文间切换。

---

## 2. 信息架构与导航层级

| 角色 | 侧边导航可见项 | 说明 |
| --- | --- | --- |
| 普通用户 | Dashboard / Health Records / Members / Profile / **User Setting** | 继续使用原设置页面（语言、密码）。 |
| 管理员 | 同普通用户 + **User Management** | 维持现有用户管理功能。 |
| 超级管理员 | 普通用户 + User Management + **Super Admin Setting** | 新增阈值治理入口。 |

### 菜单命名规范
- `User Setting`：替换原 `Settings` 文案，对应路径 `/settings`。
- `Super Admin Setting`：新菜单项，对应路径 `/super-admin/settings`。
- 所有菜单项在移动端 Drawer 与桌面侧边栏保持一致顺序；超级管理员菜单置于 User Management 之后。

## 3. 页面布局

### 3.1 Super Admin Setting 页面骨架

```
┌───────────────────────────────────────────────┐
│ Page Header：标题 + 描述                      │
├───────────────────────────────────────────────┤
│ Tabs / Segmented 控件（预留）                 │
│ ─ 指标阈值（默认）                            │
│ ─ 版本记录（可复用 Story 1.2）                │
│ ─ 审计日志（可复用 Story 1.4）                │
├───────────────────────────────────────────────┤
│ Content 容器                                  │
│ ─ Threshold Form Section（Story 1.1）         │
│ ─ Preview Panel （Story 1.3）                 │
│ ─ Help / Tips Pane                            │
├───────────────────────────────────────────────┤
│ Footer Action（预览、保存草稿、发布）          │
└───────────────────────────────────────────────┘
```

### 3.2 响应式行为
- **≥ 992px（桌面）**：页面容器宽度 960px，左右留白 24px；表单与预览并排布局（form 60%，preview 40%）。
- **< 992px（平板/移动）**：容器自适应宽度；表单与预览垂直叠放；页头按钮收敛为浮动操作条。

## 4. 交互流程

### 4.1 导航切换
1. 超级管理员登录后，点击侧边菜单 “Super Admin Setting”。
2. 若当前身份被降级（非 SUPER_ADMIN）但仍访问该 URL，路由守卫需将其重定向至 `/dashboard` 并提示 “无访问权限”。
3. 移动端抽屉中同样展示该菜单项，关闭抽屉后进入页面。

### 4.2 阈值配置主流程（Story 1.1 / 1.3 预留）
1. 页面头部显示当前阈值版本及更新时间。  
2. 管理员在表单中调整收缩压、舒张压、心率阈值，随输入即触发状态预览（Preview Panel）。  
3. 点击 “保存草稿” 保留修改；点击 “发布” 需弹窗确认，成功后触发通知。  
4. Footer Action 区域提供二次确认，使用 Ant Design `Space` + `Button` 组件。

### 4.3 版本与审计入口
- Tabs 或 Segmented 控件预留 3 个标签（阈值配置/版本记录/审计日志）。  
- 首次迭代仅显示阈值配置，其余标签置灰或提示 “即将上线”，避免跳转到空页面。

## 5. 视觉与组件规范

| 元素 | 规范 |
| --- | --- |
| 菜单图标 | 沿用 `SettingOutlined`（User Setting）与 `SafetyCertificateOutlined`（推荐 Super Admin Setting）。 |
| 颜色 | 与现有主题保持一致，Super Admin Setting 页面可加入浅蓝提示块强调权限。 |
| 表单控件 | 使用 Ant Design `Form`、`InputNumber`、`Card`；预览面板可采用 `Result` 或自定义状态卡片。 |
| 按钮样式 | 主操作 `type="primary"`（发布），次操作 `default`（保存草稿），危险操作保留 `danger` 属性。 |
| 空状态 | 使用 `Empty` 组件，提示“暂无预览数据，请输入阈值”。 |
| Loading 状态 | 使用 `Spin` 覆盖表单与预览区域。 |
| 国际化 | 所有标题、按钮、提示文案均使用 i18n key（如 `nav.userSetting`、`superAdmin.threshold.title`）。 |

---

## 6. 无障碍与引导

1. 所有交互控件需具备可焦点属性与键盘操作支持，表单字段应配置 `aria-label`。  
2. 预览区状态徽章需提供文字描述（例如 “当前读数：临界”），颜色对比度 ≥ 4.5:1。  
3. 页面顶部增加提示条，说明此页面仅超级管理员可见，并提供跳转至帮助文档的链接。  
4. 手动引导：首次进入时可展示 `Alert` 或 `Popover`，强调阈值调整对全网可见。

## 7. 交互案例

| 场景 | 行为 | 结果 |
| --- | --- | --- |
| 超级管理员点击 Super Admin Setting | 路由切换至 `/super-admin/settings`，展示阈值配置卡片 | 页面加载现有阈值，预览面板默认展示最近读数摘要 |
| 管理员尝试访问 `/super-admin/settings` | 权限校验失败 | 重定向至 `/dashboard`，显示通知 “无权限访问超级管理员设置” |
| 多语言切换 | 用户在 `User Setting` 页面切换语言 | 菜单即时更新为对应语言，高亮项保持在 `Super Admin Setting` |
| 移动端抽屉打开 | 超级管理员在手机上点击菜单按钮 | Drawer 中显示新菜单项，点击后 Drawer 关闭并跳转页面 |
