## ✅ 问题 1: 保存草稿 400 错误

### 根因
前端发送的 payload 格式不匹配：
- 前端发送: `{ thresholds: { systolic: {...}, ... } }`
- 后端期望: `{ systolic: {...}, diastolic: {...}, heart_rate: {...} }`

### 修复方案
修改 `SuperAdminSettings.js` 的 `buildPayload` 函数，去掉多余的 `thresholds` 包装层。

### 修改的文件
- ✅ [frontend/src/pages/SuperAdminSettings.js](frontend/src/pages/SuperAdminSettings.js#L265-L281)
