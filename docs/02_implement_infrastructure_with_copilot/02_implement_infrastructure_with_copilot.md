# Exercise 02: Implement infrastructure with Copilot

## Scenario

This training will have you using Copilot features for development and also to automate DevOps delivery for the Health Platform solution for JumpStarX.

In the previous exercise you set up your development environment with the current state of the Health Platform web application and installed Visual Studio Code extensions to support DevOps automation.

In this exercise, you will use GitHub Copilot to create an infrastructure GitHub issue and from Visual Studio Code you will use GitHub Copilot to generate the infrastructure Bicep scripts from the issue. This will also leverage Azure MCP Server for best practices. You will then deploy the Azure infrastructure needed to host the containerized Health Platform application for JumpStarX by running the script.

## Objectives

After completing this exercise, you'll be able to:

* Create a GitHub issue using Chat with Copilot
* Generate Bicep scripts from a GitHub issue using GitHub Copilot and Azure MCP Server
* Apply techniques for improving scripts iteratively with Copilot prompts
* Execute Bicep scripts to create infrastructure

## Duration

* **Estimated Time:** 60 minutes
