# Exercise 05: Integrate GitHub Copilot for developer productivity

## Scenario

JumpStarX is dedicated to leveraging AI not only for DevOps automation and security practices, but also to help with efficient delivery of new features in the Health Platform application. In this training you will be using Copilot to generate issues for code updates and features, and to implement those updates and features. There will be trade-offs between productivity improvements using AI, and what it would take to do the work yourself.

In this exercise, you will first use Copilot to describe and implement a backend/frontend change for the Health Platform (for example, improving health threshold visualization or member dashboards) by creating an issue using Copilot and then implementing the issue with Copilot’s help. You will then use Copilot to create a chatbot-style feature that uses the Phi-4 model to answer general health-related FAQs for JumpStarX users (without accessing real patient data).

## Objectives

After completing this exercise, you'll be able to:

- Create a GitHub issue to describe the .NET 6 update requirements
- Update the code based on the issue description, using Copilot chat inside Visual Studio Code
- Use Copilot chat to begin implementing a Chatbot feature for the solution

## Duration

* **Estimated Time:** 45 minutes
