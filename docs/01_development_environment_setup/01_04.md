# Task 04 - Build the solution

## Introduction

Now that Visual Studio Code and your development tools are setup, you can begin working on the lab. First you will need to clone the forked repository and verify the starting point of the solution.

## Description

During this task you will clone the repository you forked, and build and run the Health Platform backend and frontend to ensure you have a baseline for the next exercises.

## Success Criteria

- You have cloned the lab repository you forked
- You are able to run the Health Platform backend (Flask) and frontend (React) locally

## Learning Resources

- Cloning a repository via the [command line](https://docs.github.com/en/github/creating-cloning-and-archiving-repositories/cloning-a-repository){:target="_blank"} or [GitHub Desktop](https://docs.github.com/en/desktop/contributing-and-collaborating-using-github-desktop/cloning-a-repository-from-github-to-github-desktop){:target="_blank"}

## Key Tasks

### 01: Clone the forked repository

Clone the repository you forked to your local machine so you can work with the code locally.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Clone the repository using the git clone command:

    ```bash
    git clone https://github.com/<your-username>/<your-fork-name>.git
    ```

    Make sure to replace `<your-username>` with your actual GitHub username, and `<your-fork-name>` with the repository name where you forked the code.

2. Optionally, you can shorten the folder name by following this command with a folder name such as `health-platform-lab`:

    ```bash
    git clone https://github.com/<your-username>/<your-fork-name>.git ZavaLabFork
    ```

</details>

### 02: Build and run the solution locally

Build and run the Health Platform backend and frontend locally in Visual Studio Code to verify your development environment is configured correctly.

![Health Platform UI](../../media/0104_ui.png)

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Open the project in Visual Studio Code

    Launch VS Code and open the folder containing your cloned repository.

2. Set up and run the backend (Flask)

    In a first terminal inside VS Code, from the repository root:

    ```cmd
    cd c:\Zhuang\Source\health_platform
    python -m venv .venv
    .\.venv\Scripts\activate.bat
    pip install -r requirements.txt
    set PYTHONPATH=.
    python -m flask --app src.app run --host=0.0.0.0 --port=5000
    ```

    The backend API will listen on `http://localhost:5000`.

3. Set up and run the frontend (React)

    In a second terminal inside VS Code, from the repository root:

    ```cmd
    cd frontend
    npm install
    npm start
    ```

    The frontend will start on `http://localhost:3000` and proxy API calls to the backend.

4. Open the application in your browser

    Navigate to `http://localhost:3000` to view and interact with the running Health Platform solution.

    > **NOTE** If you encounter any issues, verify that Python and Node.js are installed, dependencies are restored, and that both backend and frontend terminals are running. You can also refer to the development guide in `docs/guides/DEVELOPMENT.md` for troubleshooting details.

</details>

## Summary

You've completed this task. You have cloned the lab repository you forked and are able to run the Health Platform backend and frontend locally.
