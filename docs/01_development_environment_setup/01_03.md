# Task 03 - Install necessary software

## Introduction

Before you clone the repository you just forked, you will set up your development environment and install the components that will be needed for this training lab.

## Description

To work through this training lab, you will need Python and Node.js to support the Health Platform backend and frontend, as well as Git, Docker, and Visual Studio Code. In addition, you will need other tools and extensions for Visual Studio Code in order to complete steps in later exercises. In this task you will install the necessary software to complete the work.

## Success Criteria

## Key Tasks

### 01: Install Python and Node.js

The Health Platform solution uses a Python/Flask backend and a React frontend. In this step you will install Python and Node.js if they are not already on your machine.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Install Python (3.10 or later)

    - **macOS**:
        - Download and install from [https://www.python.org/downloads/](https://www.python.org/downloads/){:target="_blank"}
        - Or use Homebrew:
            ```bash
            brew install python
            ```
    - **Windows**:
        - Download and run the installer from [https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/){:target="_blank"}
        - Make sure to check "Add Python to PATH" during installation.
    - **Linux**:
        - Use your distribution package manager, for example on Debian/Ubuntu:
            ```bash
            sudo apt-get update && sudo apt-get install python3 python3-venv python3-pip
            ```

2. Install Node.js (LTS)

    - **macOS / Windows / Linux**:
        - Download and install the LTS version from [https://nodejs.org/](https://nodejs.org/){:target="_blank"}
        - Or use a package manager such as `nvm` or Homebrew, for example on macOS:
            ```bash
            brew install node
            ```

3. Verify installations

    ```bash
    python --version
    node --version
    npm --version
    ```

</details>

### 02: Install Azure CLI tools

You will install the following Azure CLI tools:
- Azure CLI
- Azure Developer CLI (also known as AZD or azd)

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Install Azure CLI

    - **macOS**:
        ```bash
        brew update && brew install azure-cli
        ```
    - **Windows**:
        - Download and run the installer from [https://aka.ms/installazurecliwindows](https://aka.ms/installazurecliwindows){:target="_blank"}
    - **Linux**:
        - Run:
            ```bash
            curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash
            ```
        - For other distros, see [official docs](https://learn.microsoft.com/cli/azure/install-azure-cli){:target="_blank"}

2. Install Azure Developer CLI (azd)

    - **macOS**:
        ```bash
        brew update && brew install azure/azd/azd
        ```
    - **Windows**:
        - Download and run the installer from [https://aka.ms/azd-install](https://aka.ms/azd-install){:target="_blank"}
    - **Linux**:
        - Run:
            ```bash
            curl -fsSL https://aka.ms/install-azd.sh | bash
            ```

</details>

### 04: Install Visual Studio Code

You will install Visual Studio Code to complete development work for this lab.

<details markdown="block">

You will install several Visual Studio Code extensions to support this lab including:

3. Search for the following highlighted extensions and install them:

    ![VS Code Extensions to install](../../media/0103_extensions.png)

### 06: Install Docker Desktop

The solution will be deployed as a container, therefore you will need Docker Desktop installed.

<details markdown="block">
<summary><strong>Expand this section for detailed steps</strong></summary>

1. Install Docker Desktop

    Follow the links below to install Docker Desktop:

    - **macOS**:
        - Download and install from [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/){:target="_blank"}
    - **Windows**:
        - Download and install from [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/){:target="_blank"}

       - It is possible that you don't have the latest version of WSL (Windows Subsystem for Linux) that is required by Docker. Run the following command in an elevated PowerShell window, to ensure you have the latest version of WSL.

            ```PowerShell
            wsl --update
            ```
    - **Linux**:
        - Follow instructions for your distribution at [https://docs.docker.com/desktop/install/linux-install/](https://docs.docker.com/desktop/install/linux-install/){:target="_blank"}

</details>

## Summary

You've completed this task. You have installed Python 3.1.0 and Node.js LTS, set up your Visual Studio Code environment with necessary extensions, and installed Docker Desktop for this lab.
