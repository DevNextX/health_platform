## Epic 1 — Super Admin Threshold Governance
Goal: Provide a safe UI + API for super administrators to create, preview, and publish threshold profiles.

- Story 1.1: Draft Threshold Profile
  - As: SUPER_ADMIN
  - I want: to create and save a draft threshold profile with systolic/diastolic/heart-rate ranges
  - So that: I can iterate before publishing
  - Acceptance Criteria:
    - API `POST /api/v1/admin/thresholds/draft` accepts payload and returns 201 with saved draft
    - Validation enforces systolic range 30-250 and systolic > diastolic
    - Drafts are stored with `status=draft` and `created_by` metadata
  - Tasks:
    - Manager validation helpers in `src/manager/threshold_manager.py`
    - Service endpoint `threshold_service.py` to accept and validate requests
  - Estimate: 3 SP

- Story 1.2: Preview Draft
  - As: SUPER_ADMIN
  - I want: to preview how a draft affects sample records
  - So that: I can validate the UI impact before publishing
  - Acceptance Criteria:
    - API `GET /api/v1/thresholds/preview?draft_id=<id>&sample=30` returns labeled sample records
    - Preview uses draft values (not current active) and includes `threshold_status` per record
  - Tasks:
    - Implement preview logic in manager
    - Add preview route in `threshold_service.py`
  - Estimate: 3 SP

- Story 1.3: Publish Draft
  - As: SUPER_ADMIN
  - I want: to publish a validated draft as the active profile
  - So that: clients and downstream exports use the new profile
  - Acceptance Criteria:
    - API `POST /api/v1/admin/thresholds/publish` triggers transaction that:
      - Writes immutable record to `threshold_versions`
      - Updates `threshold_profiles` status to `active` and sets `effective_at`
      - Increments `threshold_version`
      - Writes an audit entry to `threshold_audit_log`
    - Publish returns new version and `published_at`
  - Tasks:
    - Implement `ThresholdManager.publish(profile_id, actor)` with transaction
    - Add audit write and version increment logic
    - Add RBAC checks in service layer
  - Estimate: 5 SP

## Epic 2 — Threshold Publish & Sync
Goal: Ensure published profiles are discoverable, cached safely, and clients can detect changes.

- Story 2.1: Active Profile Endpoint
  - As: any authenticated client
  - I want: to fetch the active threshold profile and version
  - So that: clients can apply consistent labels
  - Acceptance Criteria:
    - API `GET /api/v1/thresholds/active` returns `{profile, version, updated_at}` and `meta.stale=false`
    - Uses ISO 8601 with timezone
  - Tasks:
    - Add service route and manager getter
    - Add simple in-process TTL cache keyed by `threshold_version`
  - Estimate: 2 SP

- Story 2.2: Version-Based Invalidation
  - As: frontend developer
  - I want: clients to detect when `threshold_version` changes
  - So that: local caches are invalidated and UI refreshes
  - Acceptance Criteria:
    - Publish increments `threshold_version` atomically
    - Frontend receives new `version` and can compare to cached value
  - Tasks:
    - Ensure publish operation updates `threshold_version`
    - Add header or meta field in responses exposing `threshold_version`
  - Estimate: 2 SP

## Epic 4 — Audit, Export & Compliance
Goal: Maintain an immutable audit trail and support CSV exports with RFC5987 filename headers.

- Story 4.1: Audit Log on Publish/Export
  - As: compliance auditor
  - I want: all publish and export events logged with before/after payloads
  - Acceptance Criteria:
    - `threshold_audit_log` records action, actor, IP, user agent, before_payload, after_payload, created_at
    - Failure to write audit log rolls back publish
  - Tasks:
    - Implement audit writes in manager publish path
    - Add DB schema for `threshold_audit_log`
  - Estimate: 3 SP

- Story 4.2: CSV Export
  - As: SUPER_ADMIN
  - I want: to export audit events as CSV with UTF-8 BOM and RFC5987 `filename*`
  - Acceptance Criteria:
    - `GET /api/v1/admin/thresholds/audit/export?format=csv&from=&to=` streams CSV with BOM
    - Response header includes `Content-Disposition: attachment; filename*=UTF-8''threshold_audit_<date>.csv`
  - Tasks:
    - Implement streaming export in service layer
    - Ensure `ensure_ascii=False` and BOM prepended
  - Estimate: 2 SP
